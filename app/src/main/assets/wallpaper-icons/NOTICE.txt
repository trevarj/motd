MOTD Wallpaper Workshop — version 1 outline artwork

The manifest lists each motif's source and bundled license. Original artwork,
including the MOTD speech logo, emoji, game-genre and other themed drawings,
is distributed under the MOTD project's GNU GPL v3 (licenses/GPL-3.0.txt).
The games and distro products referenced in search terms do not endorse MOTD.

The graffiti-*.svg doodles and captions are original MOTD vector paths authored
with GPT-6.2-Astra. Lettering uses pen strokes, not a font; see licenses/GPL-3.0.txt.

The /motd wordmark (motd-wordmark.svg) uses the five Roboto Bold 700 glyphs,
copyright 2011 The Roboto Project Authors, from the v3.015 release:
https://github.com/googlefonts/roboto-3-classic/releases/tag/v3.015
Roboto_v3.015.zip, unhinted/static/Roboto-Bold.ttf; SHA-256:
f02bf7a9869c58b9bb61130f55c6b1a489ea85f2ac1de75b3421dcb133bc57f3
The original advances and visible contours are retained, with overlapping glyph
components united and fills replaced by monochrome strokes. No font is bundled.
Source font license: SIL Open Font License 1.1 (licenses/Roboto-OFL-1.1.txt).

Lucide: https://github.com/lucide-icons/lucide, lucide-static 1.69.0.
Sources are named per motif; unused SVG class attributes were removed, and the
original vector geometry and presentation attributes were retained. See
../lucide-static-LICENSE.txt for the upstream ISC and Feather-derived MIT
notices. The source repository records original SVGs and digests in
third_party/lucide-static/provenance.json.
