# IRC wallpaper system

The canonical wallpaper masks live in `app/src/main/assets/chat-wallpapers/` and are generated by
`tools/wallpapers/generate-wallpapers.mjs`. They are transparent, monochrome, seamless 2048×2048 PNG
tiles. The app combines each mask with a theme-derived gradient and user-controlled ink opacity.

Regenerate and verify from the pinned Nix development shell:

```sh
nix develop -c node tools/wallpapers/generate-wallpapers.mjs
nix develop -c node tools/wallpapers/generate-wallpapers.mjs --check
```

The generator intentionally uses curated placements rather than random scatter. Motifs crossing a
tile edge wrap exactly one tile apart; `WallpaperAssetTest` covers decoding, seams and bounded masks.

Custom wallpapers use the native Android image picker in Appearance. Import/Change copies a
validated image into dedicated private storage, retaining its colors and cropping it to fill;
intensity controls opacity over the theme canvas in chat and both settings previews. Remove
returns to the retained builtin fallback, while None selects the plain canvas. Cancelling or a
failed import preserves the current image. Custom image bytes and filenames are local-only and
are excluded from configuration backups.
