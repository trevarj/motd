# IRC wallpaper system

The canonical wallpaper masks live in `app/src/main/assets/chat-wallpapers/` and are generated by
`tools/wallpapers/generate-wallpapers.mjs`. They are transparent, monochrome, seamless 2048×2048
lossless indexed PNG tiles (`<preset-id>.png`), with black RGB and the approved 8-bit alpha unchanged.
The app combines each mask with a theme-derived gradient and user-controlled ink opacity.

Regenerate and verify from the pinned Nix development shell:

```sh
nix develop .#sprite-studies -c node tools/wallpapers/generate-wallpapers.mjs
nix develop .#sprite-studies -c node tools/wallpapers/generate-wallpapers.mjs --check
```

The generator uses seeded irregular placements with toroidal ink clearance. Motifs crossing a
tile edge wrap exactly one tile apart; every decoded PNG alpha byte must match the independently
verified compositor buffer. The shipped encoder uses an 8-bit palette index equal to alpha,
256 black RGB entries and exact tRNS values 0..255, filter-zero scanlines and level-9 deflate
from pinned Node's `node:zlib` (including its CRC32). No palette quantization or metadata is added.
Atlas inputs, historical masters and white/dark/offset proof images remain PNG; the ImageMagick
proof encoder is separate. PNG is retained because WebP's Android sampled decoding changes
rendered alpha despite an exact full-resolution roundtrip. `WallpaperAssetTest` freezes the
original alpha digests and covers PNG decoding, tint/direct opacity, 512dp/128dp repeats,
seams and ALPHA_8 masks; Android sampling and rendering remain unchanged.

Custom wallpapers use the native Android image picker in Appearance. Import/Change copies a
validated image into dedicated private storage, retaining its colors and cropping it to fill;
intensity controls opacity over the theme canvas in chat and both settings previews. Remove
returns to the retained builtin fallback, while None selects the plain canvas. Cancelling or a
failed import preserves the current image. Custom image bytes and filenames are local-only and
are excluded from configuration backups.
