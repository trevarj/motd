Installation

Install motd from F-Droid or GitHub, then connect to an IRC network or your bouncer.

Requirements

  • Android 8.0 or newer.
  • A 64-bit ARM device. The embedded obfuscation transport supports arm64-v8a only.

motd is a single Google-free build. Push delivery uses UnifiedPush only, not Firebase, and motd is not distributed through the Play Store.

See the installation source documentation for platform and distribution details.

F-Droid

Open motd on F-Droid and install the app with package name io.github.trevarj.motd.

F-Droid and GitHub releases share the same signing key. An installation from either channel can receive updates from the other.

The README installation section lists both supported channels.

GitHub

Download the APK from the latest GitHub release and install it on your Android device. This is the same Google-free app, with the same signing key used by F-Droid.

See the README installation section for the canonical release link and requirements.

Next steps

Follow Getting started to set up a direct IRC or soju connection. For background delivery through a compatible soju bouncer, follow the push notification guide.

The connection examples and full ntfy guide provide additional setup and troubleshooting details.
