Installation

Install motd from F-Droid or GitHub, directly or with Obtainium, or use the verified third-party OpenAPK catalogue, then connect to an IRC network or your bouncer.

Requirements

  • Android 8.0 or newer.
  • A 64-bit ARM device. The embedded obfuscation transport supports arm64-v8a only.

motd is a single Google-free build. Push delivery uses UnifiedPush only, not Firebase, and motd is not distributed through the Play Store.

See the installation source documentation for platform and distribution details.

F-Droid

Open motd on F-Droid and install the app with package name io.github.trevarj.motd.

F-Droid and GitHub releases share the same signing key. An installation from either channel can receive updates from the other.

The Android distribution runbook records channel provenance and publication status.

GitHub

Download the APK from the latest GitHub release and install it on your Android device. This is the same Google-free app, with the same signing key used by F-Droid.

See the README installation section for the canonical release link and requirements.

Obtainium

Obtainium tracks the official GitHub releases and downloads the original Google-free APK with the same signing key. This is a direct source import, not acceptance into the optional Obtainium catalogue.

With Obtainium installed, tap the badge to open its native import dialog, review the source, and confirm. It tracks stable releases by default; do not enable prereleases.

If Obtainium is not installed, get Obtainium from its official GitHub releases. If your browser cannot open the import link, open Obtainium, add an app, and paste https://github.com/trevarj/motd as the source URL.

You can always use the ordinary GitHub APK or F-Droid listing instead. motd still requires Android 8.0+ and an arm64-v8a device.

OpenAPK

OpenAPK has an existing third-party catalogue listing, not a new maintainer upload. On October 11, 2026, its actual 0.20.3 (20003) download was verified byte-for-byte against the original GitHub APK, with the same package and release signing certificate. It preserves update compatibility with GitHub and F-Droid installations.

Open the badge to visit the package page and download the APK. motd remains Android 8.0+ and arm64-v8a only, regardless of generic 32-bit/x86 claims on the catalogue download page. See the distribution runbook for verification evidence and provenance.
