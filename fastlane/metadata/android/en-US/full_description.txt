motd is a native Android IRC client with a modern chat interface. Connect directly to IRC networks or use a soju or ZNC bouncer.

Features:

* Local message history and full-text search across chats or within one conversation, with jump-to-message
* Bouncer history and synchronized read markers where supported; soju multi-network management and ZNC playback
* Replies, reactions, typing indicators, nick autocomplete, and slash commands, depending on server capabilities
* Inline images, link previews including YouTube videos, and file uploads, with remote-media controls
* Chat folders, pinned chats, and an archive
* Material You dynamic color, curated themes, light, dark and AMOLED modes, adjustable text sizes, and message styles
* Builtin and custom-image wallpapers, including the System Crafters preset and selectable builtin outline colors
* TLS, SASL PLAIN and EXTERNAL, and client certificates

motd is Google-free and uses UnifiedPush for push delivery, not Firebase. Push requires a compatible server or bouncer and an installed UnifiedPush distributor. Persistent socket delivery is also available. Plain IRC networks retain local history; remote history, read-state sync and push depend on the server or bouncer.

Optional per-network routing supports SOCKS5, Tor through Orbot, and embedded VLESS with TCP + REALITY or WebSocket + TLS. Embedded VLESS requires a compatible proxy server and is limited to arm64-v8a. Routing is not a guarantee of anonymity.

An opt-in read-aloud feature uses installed Android offline voices. Third-party speech engines still receive the text they read.

Requires Android 8.0 or newer and a 64-bit ARM device.
